- **Backend & Datos:** Python, MySQL, Firebase
- **Automatización:** n8n, integración con WhatsApp

#### 🚀 Experiencia y Soluciones Desarrolladas
- **Locolindo:** Aplicación web de interfaz de meseros, catálogo digital y panel administrativo.
- **Don Ceferino:** Sistema de control de inventario, ventas online y automatización de pedidos.
- **Rika Papa:** Sistema web integral para gestión de pedidos, stock y personal.
